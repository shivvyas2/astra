Sanchara

Engineering Handbook

Shiv Vyas · Revision A

Sanchara is an astrology app built on one rule: nothing about the chart is guessed. The Swiss Ephemeris computes a person's real birth chart (planets, houses, nakshatras, dashas, doshas, transits and numerology) from their birth date, time and place, and Claude interprets only those computed facts. It ships as a Next.js web app on Vercel and a native SwiftUI app for iOS, both on one API and one Supabase project. This handbook is the single reference for how it is built, why it is built that way, what keeps it fast and cheap, and what it does when things go wrong. It is written to be studied: every chapter ends with a reading order through the code and questions to check yourself against.
