All three exports are 1024 × 1024 opaque PNG files with square corners. These are concept alternatives for review, using flat PNG exports to match this repository's existing universal iOS app-icon catalog. They are not layered Icon Composer documents or a full set of appearance variants.

Apple applies the outer icon mask. The same source dimensions apply to iOS and iPadOS: [Apple app-icon design guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons).

The palette brief uses the current app tokens in Theme.swift and app/globals.css: near-black #0A0A0B, bone #F4F1EA, lime #DFEE6B, ember #FF6B3D, and violet #7C6CFF. Generated concepts approximate these colors; a selected mark can be finalized as precise vector artwork.

The complete prompts are in [prompts.md](prompts.md). Original generated masters remain in the Codex generated_images directory; these delivery copies were resampled to 1024 × 1024 using macOS sips. The installed app icon and existing source changes have not been modified.
