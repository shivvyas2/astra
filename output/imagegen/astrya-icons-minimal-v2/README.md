# Astrya — minimal brutalist revision

Created with the built-in image_gen tool. The user requested a more minimal, brutalist direction.

| Concept | Export | Design |
| --- | --- | --- |
| 01 · Stencil A | [PNG](01-stencil-a.png) | One massive lime monogram with an eclipse-like circular counter. Strongest Astrya identity. |
| 02 · Solar Diamond | [PNG](02-solar-diamond.png) | A heavy bone diamond frame and ember sun on near-black. Simplified Vedic geometry. |
| 03 · Split Eclipse | [PNG](03-split-eclipse.png) | A black split disc on lime. The most minimal, abstract celestial option. |

All three are square 1024 × 1024 opaque PNG concept exports for the current iOS/iPadOS asset-catalog workflow. No outer rounding is baked in. They are flat concepts, not layered Icon Composer files.

The generation brief uses Astrya's current palette: near-black #0A0A0B, bone #F4F1EA, lime #DFEE6B and ember #FF6B3D. Generated colors are approximate; a selected mark can be finalized with exact vector geometry and palette values.

[Full generation prompts and reference paths](prompts.md). The delivery files were resampled with macOS sips. The first-round concepts and original app assets are preserved.
