# Astrya — typography as the icon

Three concepts created using the built-in image_gen tool. The user requested the complete Astrya name written creatively, with the icon built around the name and the app's concept, while retaining minimal brutalist styling.

| Option | Export | Concept |
| --- | --- | --- |
| 01 · Astrya Matrix | [PNG](01-astrya-matrix.png) | AST over RYA, lime on near-black. Circular counters suggest celestial bodies, with a measured modular composition. Recommended for the app icon. |
| 02 · Kundli Type | [PNG](02-astrya-kundli-type.png) | AST over RYA, angular lettering with diamond counters inspired by Vedic chart geometry. Bone, ink, and an ember final A. |
| 03 · Astrya Horizon | [PNG](03-astrya-horizon.png) | ASTRYA on one line, black on lime, with a horizon cut through the lettering. Strong wordmark direction; smaller letters than the stacked options. |

The numerical feeling comes from the ordered letter construction; no numerological formula or calculation is claimed.

All exports are square 1024 × 1024 opaque PNGs, with no baked-in rounded corners. These are flat concept assets for the repository's current app-icon workflow, not layered Icon Composer documents. Original app assets and previous concepts are preserved.

Palette brief: near-black #0A0A0B, bone #F4F1EA, lime #DFEE6B, ember #FF6B3D. Generated colors and geometry are approximate. A selected direction can be finalized as precise vector artwork.

[Complete prompts](prompts.md). PNG delivery copies were resampled with macOS sips; original generated masters remain in the Codex generated_images directory.
